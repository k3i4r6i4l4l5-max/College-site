# Тестирование

## Команды

Production-сборка:

```sh
npm run build
```

Unit-тесты:

```sh
npm test
```

Сборка и unit-тесты:

```sh
npm run check
```

Браузерные сценарии при работающем dev-сервере:

```sh
npm run dev
npm run test:e2e
```

## Unit-тесты

Каталог `tests` проверяет:

- ограничение прогресса диапазоном от 0 до 100;
- распределение карточек по уровням знания;
- ранжирование проблемных карточек;
- хронологию активности;
- формирование плана подготовки;
- определение текущего дня плана.

## E2E-сценарии

`scripts/smoke.cjs` запускает сценарии из `scripts/e2e`:

- первый тестовый вход, onboarding и восстановление сессии;
- поиск и фильтрацию без потери фокуса;
- прохождение и продолжение тренировки;
- создание и изменение плана подготовки.

Сценарии используют отдельные страницы браузера и очищают локальное хранилище перед началом независимого потока.
