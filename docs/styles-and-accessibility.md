# Стили и доступность

## Организация CSS

`src/app/styles.css` импортирует стили в определённом порядке:

1. базовые переменные и сброс;
2. каркас приложения;
3. общие компоненты;
4. стили отдельных страниц;
5. настройки темы и типографики.

| Файл или каталог | Область ответственности |
| --- | --- |
| `src/app/styles/base.css` | Переменные, сброс и базовые элементы. |
| `src/app/styles/layout.css` | Навигация, контейнеры и сайдбары. |
| `src/app/styles/components.css` | Кнопки, индикаторы и общие состояния. |
| `src/app/styles/async-states.css` | Skeleton, ошибка и отсутствие данных. |
| `src/widgets/preparation-plan-sidebar/ui` | Сложные переиспользуемые блоки. |
| `src/pages/*/ui` | Изолированные стили маршрутов. |
| `src/app/styles/typography.css` | Типографические роли. |

Основные адаптивные границы: `1280px`, `800px`, `700px`, `560px`, `520px` и `420px`.

## Темы и настройки

На элементе `html` используются атрибуты:

- `data-theme`;
- `data-reduce-motion`;
- `data-text-size`.

Настройки применяются до первого React-рендера, что предотвращает вспышку неправильной темы.

## Доступность

- progress bar содержит ARIA-значения;
- dropdown использует семантику списка выбора;
- переключатели имеют `aria-pressed` или `role="switch"`;
- модальные панели имеют `role="dialog"` и `aria-modal`;
- панели закрываются клавишей `Escape` и нажатием на backdrop;
- присутствует skip-link к основному содержимому;
- интерактивные элементы доступны с клавиатуры;
- анимации учитывают пользовательскую настройку и `prefers-reduced-motion`;
- ошибки отдельных секций изолированы Error Boundary.
