# Возможности и маршруты

## Что реализовано

- регистрация, вход и тестовый вход;
- одноразовый onboarding-гайд после первого тестового входа;
- каталог курсов с поиском, фильтрами и сортировкой;
- страницы курсов и конспекты тем;
- тренировки с самооценкой ответа;
- продолжение незавершённой тренировки;
- прогресс, история ответов и проблемные карточки;
- профиль и аналитика активности;
- управление курсами пользователя;
- план подготовки;
- светлая и тёмная темы, размер текста и уменьшение анимаций;
- состояния загрузки, отсутствия данных и ошибки.

## Маршруты

| Маршрут | Страница | Назначение |
| --- | --- | --- |
| `/` | `CoursesPage` | Каталог, рекомендации и продолжение обучения. |
| `/courses/:id` | `CoursePage` | Курс, общий прогресс и список тем. |
| `/topics/:id` | `TopicPage` | Конспект темы и запуск тренировки. |
| `/training` | `TrainingPage` | Прохождение карточек и самооценка. |
| `/progress` | `ProgressPage` | Прогресс, слабые темы и динамика знаний. |
| `/community` | `CommunityPage` | Официальные и пользовательские курсы. |
| `/profile` | `ProfilePage` | Профиль, курсы и аналитика. |
| `/settings` | `SettingsPage` | Настройки интерфейса и аккаунта. |

Маршрутизация построена на `HashRouter`, чтобы внутренние страницы корректно работали на GitHub Pages.

## Тренировки

Состав тренировки задаётся query-параметрами:

| Пример | Результат |
| --- | --- |
| `?topic=core` | Все карточки темы. |
| `?topic=core&card=1` | Одна карточка темы. |
| `?course=java` | Все карточки курса. |
| `?mode=weak` | Карточки слабых начатых тем. |
| `?course=java&mode=course-weak` | Слабые темы выбранного курса. |

В mock-режиме оценка «Знаю» добавляет 5 пунктов прогресса, «Не уверен» вычитает 2, «Не знаю» вычитает 7. Значение ограничено диапазоном от 0 до 100.

## Onboarding

Страница `public/guide.html` содержит пошаговую презентацию с реальными фрагментами интерфейса. После первого тестового входа пользователь перенаправляется на гайд. Нажатие «Ясно» сохраняет признак просмотра и возвращает в приложение.
