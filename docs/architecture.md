# Архитектура frontend

Проект использует Feature-Sliced Design. Зависимости направлены сверху вниз:

`app → pages → widgets → features → entities → shared`.

Срезы внутри одного слоя не импортируют друг друга. Внешние импорты обращаются к `index.js` среза. Команда `npm run check:architecture` проверяет эти правила и разрешение относительных импортов.

## Ответственность слоёв

| Слой | Ответственность в проекте |
| --- | --- |
| `app` | Инициализация React, роутер, общий каркас, начальная загрузка данных, mock-backend для разработки и глобальные стили. |
| `pages` | Маршруты и их локальный UI: каталог, курс, тема, тренировка, прогресс, профиль и настройки. |
| `widgets` | Самостоятельные блоки: навигация, боковые панели, графики, списки и раскрывающиеся сведения о курсах. |
| `features` | Действия пользователя: авторизация, самооценка карточки, создание плана и отметка занятия. |
| `entities` | Каталог, пользователь, тренировочная сессия, прогресс, активность и план подготовки: модели, расчёты и API. |
| `shared` | HTTP-транспорт, общие элементы UI, утилиты и ключи браузерного хранилища. |

## Данные и запросы

`src/shared/api/request.js` переключает настоящий HTTP API и mock-backend. Mock-реализация подключается из `app` только в режиме `VITE_DATA_SOURCE=mock`. Доменные сервисы находятся в срезах соответствующих сущностей, а сервис авторизации — в `features/auth`. Страницы и виджеты не вызывают `fetch` напрямую.

`src/app/App.jsx` восстанавливает сессию и загружает каталог, прогресс, активность, настройки, курсы пользователя, тренировку и план. Локальное состояние форм и панелей остаётся рядом с их UI. `CatalogProvider` принадлежит срезу `entities/catalog`.

## Стили

`src/app/styles.css` сохраняет порядок каскада. Общие стили лежат в `app/styles`, стили маршрутов — рядом с соответствующей страницей, стили панели плана — рядом с виджетом. Используются системные шрифты без засечек.

## Mock и backend

В mock-режиме расчёт прогресса, планов и часть аналитики выполняются в браузере. При подключении backend сервер должен стать источником истины; транспортный слой позволяет менять источник без прямых запросов из UI.
