# Данные, mock-backend и API

## Выбор источника

Настройки находятся в `.env.example`:

```env
VITE_DATA_SOURCE=mock
VITE_API_URL=http://127.0.0.1:8080/api/v1
```

- `mock` включает локальную реализацию backend;
- `api` включает настоящие HTTP-запросы;
- `VITE_API_URL` задаёт базовый адрес сервера.

## Модули

| Файл | Назначение |
| --- | --- |
| `src/api/client.js` | HTTP-запросы, JSON, cookies и стандартные ошибки. |
| `src/api/request.js` | Переключение между mock и API. |
| `src/api/serviceModules.js` | Методы доменных сервисов и адреса endpoint. |
| `src/api/domainServices.js` | Единая точка импорта сервисов. |
| `src/api/mockBackend.js` | Совместимая локальная реализация запросов. |

## Группы API

- авторизация и восстановление сессии;
- профиль, пароль и настройки;
- каталог курсов и тем;
- курсы пользователя;
- тренировочные сессии и ответы;
- прогресс и активность;
- планы подготовки.

Запросы отправляются с `credentials: include`. Ответ `401` создаёт событие `practice:unauthorized`, после которого приложение сбрасывает клиентскую сессию.

## LocalStorage в mock-режиме

| Ключ | Данные |
| --- | --- |
| `practice-auth-v1` | Признак активной mock-сессии. |
| `practice-user-v1` | Профиль пользователя. |
| `practice-settings-v1` | Тема, размер текста и уменьшение анимаций. |
| `practice-progress-v1` | Прогресс по темам. |
| `practice-activity-v2` | История ответов. |
| `practice-active-training-v1` | Незавершённая тренировка. |
| `practice-user-courses-v1` | Курсы пользователя и их состояния. |
| `practice-preparation-plan-v1` | Активный план подготовки. |
| `practice-onboarding-seen-v1` | Признак завершённого onboarding. |

В production пользовательские данные, сессии, ответы, прогресс и планы должны храниться на backend. В браузере допустимо оставить интерфейсные настройки и безопасный кеш.
