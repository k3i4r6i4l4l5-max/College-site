# Данные, mock-backend и API

## Выбор источника

`VITE_DATA_SOURCE=mock` использует локальный backend, `VITE_DATA_SOURCE=api` — HTTP. Базовый адрес задаёт `VITE_API_URL`; пример находится в `.env.example`.

| Путь | Назначение |
| --- | --- |
| `src/shared/api/client.js` | HTTP-запросы, JSON, cookies и стандартные ошибки. |
| `src/shared/api/request.js` | Единый запрос и переключение источника. |
| `src/app/mockBackend.js` | Локальная реализация запросов. Загружается только в mock-режиме. |
| `src/features/auth/api` | Авторизация и восстановление сессии. |
| `src/entities/*/api` | Запросы соответствующей предметной области. |

Запросы к серверу отправляются с `credentials: include`. Ответ `401` создаёт событие `practice:unauthorized`, после которого приложение сбрасывает клиентскую сессию.

В mock-режиме аккаунты, ответы, прогресс, курсы пользователя и планы сохраняются в `localStorage` под ключами из `src/shared/config/storageKeys.js`. При подключении backend эти данные должен хранить сервер; браузер может сохранять интерфейсные настройки и безопасный кэш.
